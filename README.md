### 👋 About me

I run **The Brand NERVE**, a Lagos-based creative technology studio, and I build at the intersection of **motion graphics, AI-powered media, and workflow automation**. My background spans medicine, cinematography, drone piloting, frontend development, and automation engineering — about 8 years into a tech journey now, with the long-term goal of building The Brand NERVE into a world-class skills incubation hub.

- 🎬 Producing AI-powered motion graphics and Vox-style explainer videos
- 🤖 Building n8n + AI automation systems for real businesses (real estate, e-commerce, delivery/logistics)
- 🧠 Developing **Boss Agent** — a personal AI operating system with a human-approval loop
- 🌍 Building AI tools for underserved contexts, like a maternal health assistant for Nigeria and sub-Saharan Africa
- 📈 Writing on LinkedIn about entrepreneurship, automation, and resilience
- 💼 Also work in real estate and finance alongside running the studio

### 🚀 Featured Work

**Automation Systems**
- **Real Estate Lead Qualifier** — n8n + Google Sheets CRM with a live frontend for Lagos property listings, webhook-driven intake → [nerverealestate.netlify.app](https://nerverealestate.netlify.app)
- **Water Factory Delivery System** — end-to-end ordering and delivery automation using n8n, Telegram, and Paystack
- **OGWears E-commerce Automation** — a 108-node n8n workflow tying together Telegram, Groq AI, Paystack, Gmail, and Netlify for a full storefront-to-fulfillment pipeline
- **Boss Agent** — a personal AI operating system built on the Claude API, n8n, Evolution API (WhatsApp), Supabase, Airtable, Next.js, and Railway — with a YES/EDIT/NO human-approval loop before any action executes

**AI & Media Production**
- **Pregnancy Companion** — an AI maternal health assistant for Nigeria and sub-Saharan Africa, with voice guidance and fetal development tracking → [pregnancy-companion.netlify.app](https://pregnancy-companion.netlify.app)
- **Vox-style Explainer Videos** — full production pipeline (storyline → AI image prompts → ElevenLabs voiceover), including "The Shape of Speed" (Ford Mustang history) and "Ten Teams. One Truth" (F1 explainer)
- **WAFCON Morocco 2026 Pitch** — media/content and pre-match ceremony production pitch for CAF's WAFCON tournament
